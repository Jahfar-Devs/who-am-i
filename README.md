# Jahfar Swadikh K — Portfolio

Animated one-page portfolio with a built-in admin panel. Next.js 16 (App Router), Tailwind CSS 4, Motion, Lenis.

## Run

```bash
npm install
npm run dev
```

Site: http://localhost:3000 · Admin: http://localhost:3000/admin

## Admin panel

- Sign in with the `ADMIN_PASSWORD` from `.env.local` (copy `.env.example` if the file is missing, then restart).
- Every section is editable: loading screen, hero, stats, tech ticker, about, services, projects, experience, skills, education and awards, testimonials, contact, navigation, theme/SEO and footer.
- **Section order** reorders the page and shows or hides sections. **Media library** holds uploaded images and PDFs. **Messages** collects contact-form submissions. **Backup and reset** exports, imports or resets all content.
- Saving updates the live site immediately (the cached page is revalidated).

## Where things live

| Path | What |
| --- | --- |
| `src/lib/default-content.ts` | Seed content and the content schema (`Content` type) |
| `src/components/admin/schema.ts` | Which fields the admin form shows for each section |
| `src/components/site/` | Public page sections and animations |
| `src/app/api/` | Admin, media and contact endpoints |
| `data/content.json` | Saved content (created on first save) |
| `data/uploads/` | Uploaded files, served at `/media/<name>` |
| `data/messages.json` | Contact-form messages |

To add a new editable field: add it to `default-content.ts`, add one line to `schema.ts`, and render it in the section component.

## Deploying

Content, uploads and messages are stored as files in `./data`, so the host needs a persistent, writable disk: a VPS, DigitalOcean droplet/App Platform with a volume, or Hostinger Node hosting (`npm run build && npm start`). On serverless hosts such as Vercel the disk is read-only, so admin edits will not persist there unless `src/lib/store.ts` is switched to a database and blob storage.

Set `ADMIN_PASSWORD` and `ADMIN_SESSION_SECRET` as environment variables in production.

Placeholder artwork is generated by `node scripts/make-placeholders.mjs`.
