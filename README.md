# Jahfar Swadikh K — Portfolio

Animated one-page portfolio with a built-in admin panel. Next.js 16 (App Router), Tailwind CSS 4, Motion, Lenis.

## Run

```bash
npm install
npm run db:migrate:local   # first run only: creates the local D1 tables
npm run dev
```

Needs Node.js 22.12 or newer (required by Wrangler). Local development uses a local D1 database and R2 bucket simulated by Wrangler in `.wrangler/`, not the production data.

Site: http://localhost:3000 · Admin: http://localhost:3000/admin

## Admin panel

- Sign in with the `ADMIN_PASSWORD` from `.env.local` (copy `.env.example` if the file is missing, then restart).
- Every section is editable: loading screen, hero, stats, tech ticker, about, services, projects, experience, skills, education and awards, testimonials, contact, navigation, theme/SEO and footer.
- **Section order** reorders the page and shows or hides sections. **Media library** holds uploaded images and PDFs. **Messages** collects contact-form submissions. **Backup and reset** exports, imports or resets all content.
- Saving updates the live site immediately.

## Where things live

| Path | What |
| --- | --- |
| `src/lib/default-content.ts` | Seed content and the content schema (`Content` type) |
| `src/components/admin/schema.ts` | Which fields the admin form shows for each section |
| `src/components/site/` | Public page sections and animations |
| `src/app/api/` | Admin, media and contact endpoints |
| `src/lib/store.ts` | Storage layer: content and messages in D1, uploads in R2 |
| `migrations/` | D1 schema (`content` and `messages` tables) |
| `wrangler.jsonc` | Cloudflare Worker config: account, D1 binding `DB`, R2 binding `MEDIA` |

To add a new editable field: add it to `default-content.ts`, add one line to `schema.ts`, and render it in the section component.

## Deploying

The site runs on Cloudflare Workers through the [OpenNext Cloudflare adapter](https://opennext.js.org/cloudflare). Content and contact messages are stored in a D1 database (`jahfar-portfolio`), and uploaded files in an R2 bucket (`jahfar-portfolio-media`), served at `/media/<name>`.

```bash
npm run deploy       # build and deploy the Worker
npm run db:migrate   # apply new files in migrations/ to the production database
npm run preview      # run the production build locally in the Workers runtime
```

`wrangler.jsonc` pins the Cloudflare account, so Wrangler must be signed in to that account (`npx wrangler whoami`).

`ADMIN_PASSWORD` and `ADMIN_SESSION_SECRET` are Worker secrets in production. Change one with `npx wrangler secret put ADMIN_PASSWORD`.

Placeholder artwork is generated by `node scripts/make-placeholders.mjs`.
